# AgendeZap — Partes 1 e 2

Projeto React + Vite + Tailwind CSS com landing page, site modelo da Barbearia Dom Lucas e agendamento frontend demonstrativo.

## Executar no Windows (PowerShell)

1. Extraia este ZIP para uma pasta.
2. Abra o PowerShell dentro da pasta `agendezap` (a pasta que contém `package.json`).
3. Execute `npm.cmd install`.
4. Execute `npm.cmd run dev`.
5. Abra o endereço indicado no terminal, geralmente http://localhost:5173/.

Endereços: `/` (landing), `/demo` (barbearia), `/agendar` (agendamento).

**Importante:** o projeto não tem backend. Agendamentos, profissionais, preços, avaliações e endereço são fictícios. Login e dashboard serão implementados na Parte 3.
